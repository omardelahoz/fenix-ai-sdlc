# Database Expert Checklist

## Before Modeling
- [ ] Architecture approved
- [ ] Data standards loaded
- [ ] Domain entities understood

---

## During Design
- [ ] Proper normalization applied
- [ ] Primary and foreign keys defined
- [ ] Indexes added for query performance
- [ ] Data types chosen correctly

---

## Before Completion
- [ ] SQL syntax validated
- [ ] Migrations are safe (no accidental data loss)
- [ ] Data decisions updated in Memory
