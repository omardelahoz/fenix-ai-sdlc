# Good Example

Input

Story:
Create endpoint to retrieve customers by id.

Acceptance Criteria
- Returns HTTP 200
- Returns HTTP 404 when customer does not exist
- Swagger documentation required

Expected Result
- Controller
- Service
- Repository
- DTO
- Unit Tests
- Swagger documentation
- XML comments
